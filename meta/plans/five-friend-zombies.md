# Five Friend Zombie Types

## Goal
Replace the generic zombie identities with five distinct friend-inspired zombie types while preserving the existing runtime animation contract: four directions, idle/walk/attack, transparent 4x4 sheets, 128px tiles, weapon separate from survivor.

## Pipeline
- [x] Confirm five references and choose one type per person
- [x] Create identity generation metadata
- [x] Generate five full-body identity anchors
- [x] Review identity consistency and silhouettes
- [x] Create four-direction masters
- [x] Generate idle/walk/attack clips (Kling/Wan/Wan API/FLUX with procedural recovery)
- [x] Convert clips to transparent 4x4 sheets
- [x] Integrate five IDs into runtime
- [x] Browser regression and chronological action log

## Types
- Blonde woman: The Glamour Drifter
- Moustached man: The Office Runner
- Bearded man: The Heavy Spitter
- Dark-haired woman: The Silent Stalker
- Brunette woman: The Boss Zombie

## Constraints
Non-graphic, playful zombie comedy; no gore pile, no dismemberment, no weapons. Preserve recognizable hair, face shape, and distinguishing features from each supplied reference. Keep the project's photoreal survival-game style and neutral studio lighting for asset generation.
