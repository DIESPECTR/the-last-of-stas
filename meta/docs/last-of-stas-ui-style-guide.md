# The Last of Stas — UI Style Guide

## Direction
Original restrained survival-horror UI: utilitarian, tactile, quiet. Inspired by the emotional restraint and organic decay of modern post-apocalyptic interfaces without copying another game's layouts, marks or assets.

## Tokens
- Background: `#0b0d0c`
- Surface: `#151815`
- Border: `#3b4039`
- Primary text: `#e7e4da`
- Secondary text: `#999d91`
- Moss action: `#8d9a68`
- Rust danger/action: `#a94734`

## Typography
- Display: Barlow Condensed 700–800, uppercase.
- Data/control copy: IBM Plex Mono 400–600.
- Small metadata uses wide tracking; body copy does not.

## Components
- Primary CTA: moss fill, dark label, 44px minimum height.
- Destructive/crafting CTA: restrained rust fill.
- Secondary button: dark surface with one-pixel border.
- Panels: charcoal translucent surface, subtle salvaged texture, thin moss registration line.
- Status messages: compact dark overlay with a moss left marker.

## Accessibility
- Minimum 44px controls.
- Visible keyboard focus.
- No color-only state communication.
- Reduced-motion media query.
- Desktop sidebar becomes a normal document flow below 980px.
